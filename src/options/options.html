Privacy & IP

Extra protection on top of ad blocking. Changes apply instantly.

Hide your IP address

Route browsing through a proxy
Websites see the proxy's IP instead of yours. dx.block doesn't run servers itself: use Tor (free, run Tor or Tor Browser on this computer) or the SOCKS5/HTTP details from your VPN or proxy provider.

Tip: if pages stop loading, the proxy isn't running. Switch it off here to go back to a direct connection.

Clean up

Forget sites when I leave
When the last tab of a site closes, its cookies and stored data are deleted after 15 seconds, so it can't recognise you next time. Sites below (and sites where dx.block is switched off) are kept, so you stay logged in.

Extras

Data breaches

Find out if your accounts were in a data leak and what was exposed, so you know which passwords to change.

Check an email address

The address is sent over HTTPS to XposedOrNot, a free, open breach database, and nowhere else. The details for each breach come from Have I Been Pwned’s public list, which dx.block keeps locally.

Saved addresses

    Check a password

    Your password never leaves this computer. dx.block scrambles it (SHA-1) and sends only the first 5 of its 40 characters to Have I Been Pwned’s Pwned Passwords service, which sends back every leaked password starting with those characters. The match is checked here.

    My filters

    One filter per line. Adblock Plus, uBlock Origin and AdGuard syntax all work.

    Filter syntax cheat sheet
    ||ads.example.com^Block a domain and its subdomains
    /banner/*.gif$imageBlock matching images
    ||tracker.com^$third-partyOnly when loaded by other sites
    @@||example.com^$documentTurn blocking off on a site
    example.com##.ad-boxHide elements on one site
    ##.ad-boxHide elements everywhere
    example.com##div:has-text(Sponsored)Procedural hiding
    example.com##+js(abort-on-property-read, adBlockDetected)Run a scriptlet

      About

      dx.block

      An open-source ad blocker for Brave, Chrome and other Chromium browsers. Free software under the GNU GPL v3.

      Keyboard & menus

      Right-click any page → Block element…, or set a shortcut for “Block an element” at brave://extensions/shortcuts.
